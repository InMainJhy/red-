# Harmony 首页视觉升级设计

## 背景

当前 Harmony 首页的交互结构已经可用，问题主要在视觉语言：背景光效偏散、首页大功能卡片偏“可爱活动页”，而不是更高级、更克制的产品首页。用户这次明确要求保留现有首页结构，只做 UI 美化，并优先优化背景、大功能卡片和整体色彩搭配。

## 目标

1. 不调整首页信息结构和主要导航路径。
2. 把首页视觉收口到更高级、更克制的冷调设计语言。
3. 重点提升大功能卡片的质感与记忆点，让它们从普通功能块变成更有设计感的首页资产。
4. 统一背景、卡片边框、阴影、色块和强调色，减少当前页面中略显松散的糖感与玩具感。

## 非目标

1. 不重构首页模块顺序。
2. 不修改会议、角色、纪要等业务逻辑。
3. 不新增复杂交互动效。
4. 不把首页彻底改成新概念稿或全新排版。

## 设计方向

本次采用“冷调海报拼贴 + 雾面产品感”的视觉方向：

1. 背景从多团高饱和漂浮渐变，收成更大面积、更低对比的雾面蓝灰空间。
2. 大功能卡片保留现有 2x2 布局，但改为“海报拼贴卡”风格：使用轻错位底板、裁切色块、编号、细边和更利落的排版。
3. 角色区与次级卡片不做激进变形，只跟随新的配色和边框规则，维持整体统一。

## 具体改造

### 1. 背景

背景改为更安静的大面积冷白蓝雾面：

1. 减少当前多个大小接近的高光团块。
2. 保留少量远景冷色光斑，弱化绿色倾向。
3. 通过顶部到下方的轻微层次过渡，让内容区更突出。

### 2. 大功能卡片

大功能卡片是本次改造核心：

1. 保留现有点击区域和 2x2 栅格，不改布局逻辑。
2. 引入双层或三层卡片结构，形成“底板 + 主卡 + 裁切片”的拼贴关系。
3. 弱化目前偏可爱 mascot 主导的视觉，保留角色感但不再让吉祥物抢占卡片焦点。
4. 标题、编号、动作标签和辅助文字形成更清晰的版式秩序。
5. 颜色改成低饱和雾蓝、石板灰、冷白与一点淡青蓝，避免卡片一张一个世界。

### 3. 次级卡片统一

首页其余卡片不重做结构，但做统一质感升级：

1. 日历、最近会议、准备卡片和空态卡片采用更一致的边框和阴影。
2. 减少过亮渐变与果冻玻璃感。
3. 让卡片更像同一产品体系，而不是不同阶段拼接产物。

## 验收标准

1. 首页第一眼更高级、更安静，不再偏活动页。
2. 大功能卡片有明显设计升级，但不影响可点性和文本可读性。
3. 页面整体配色更统一，强调色更节制。
4. 首页结构、逻辑、跳转行为与当前版本保持一致。
